# Korsche Frame

## About

Korsche Frame is a simple Android app that is designed to run in landscape mode on my Kindle Fire 6 tablet. It is a barebones app built with [MIT App Inventor](https://appinventor.mit.edu/).

Art is generated using xAI models with Gemini doing some supplemental work. A new image is created every day using GitHub Actions.

## Download

[KorscheFrame.apk](https://github.com/andreburto/korschedotlink/blob/master/frame/KorscheFrame.apk) will take you to the file.
